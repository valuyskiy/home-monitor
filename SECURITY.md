# Security Policy

## Reporting a vulnerability

Do not publish credentials or exploitable details in a public issue. Contact the repository maintainer privately using the contact method listed in the GitHub profile.

## Sensitive data

The `.env` file contains Telegram and Home Assistant credentials. Keep it private, use restrictive file permissions, and rotate credentials immediately if they are exposed.

Do not include secrets, private IP plans, personal chat IDs, or unredacted logs in bug reports.
