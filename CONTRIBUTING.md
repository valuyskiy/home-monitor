# Contributing

Спасибо за интерес к проекту!

## Как предложить изменение

1. Создайте fork репозитория.
2. Создайте отдельную ветку для изменения.
3. Опишите проблему и ожидаемое поведение.
4. Перед Pull Request проверьте синтаксис:

   ```bash
   python3 -m py_compile monitor.py
   ```

5. Убедитесь, что в изменениях нет токенов, IP-адресов и других приватных данных.

## Отчёты об ошибках

Укажите:
- версию Python и Linux;
- ожидаемое и фактическое поведение;
- относящиеся к проблеме сообщения журнала после удаления секретов.

Никогда не прикладывайте `.env`, токены, полные URL с секретами или резервные копии конфигурации.
